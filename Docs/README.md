## Conventions

- Prefer **relative markdown links** so GitHub and Obsidian both work.
- Obsidian wiki links also work: `[[Algorithms/noise-and-fbm]]`.
- Screenshots go in `Docs/assets/` and are referenced as `Docs/assets/filename.png` from the vault root README, or `../Docs/assets/...` from nested notes.
- Study notes follow a light template: **What / Why → How → Screenshot → Code pointers**.
